# Wireframes

## Wireframe vsi projekti
Pregled vseh projektov. Pri vsakem projektu so prikazane osnovne informacije. Ob kliku na projekt se odpre pregled posameznega projekta.

![vsi_projekti](wireframes/projekti_tab.png)




## Wireframe pregled - projekt
Pregled posameznega projekta. To je glavno okno za pregled in urejanje projekta. Vnosna polja, seznami, checkboxi... različni elementi za različne podatkovne tipe.
