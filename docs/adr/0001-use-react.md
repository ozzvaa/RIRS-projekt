# Uporaba Reacta za razvoj čelnega dela aplikacije

## Kontekst in opis problema

Aplikacija potrebuje pregledno vstopno točko za prikaz in urejanje podatkov s komunikacijo z zalednim delom. React omogoča ustvarjanje in ponovno uporabo komponent za prikaz in urejanje podatkov ter dobro integracijo z okoljem NodeJS, zalednim delom Expressa in strogo tipizacijo z uporabo TypeScripta.


## Obravnavane možnosti

* Plain TypeScript
* Angular 
* VueJS
* React


## Sprejeta odločitev

Izbral sem tehnologijo React, saj omogoča enostavno integracijo TypeScripta s predlogami, komunikacijo z Expressom in ima velik ekosistem knjižnic ter obširno dokumentacijo s primeri. NodeJS zagotavlja uporabo istega programskega jezika na čelnem in zalednem delu kar omogoča lažje programiranje.


### Posledice

* Pozitivno: standardni izbor za komunikacijo z expressovim zalednim delom.
* Pozitivno: dobra podpora za TypeScript in številne dodatne knjižnice.
* Pozitivno: komponente omogočajo ponovno uporabo kode in lažje vzdrževanje.
* Negativno: za naprednejše funkcionalnosti odvisnost od zunanjih knjižnic
